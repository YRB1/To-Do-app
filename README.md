# To-Do App

A simple and responsive To-Do application built using **HTML, CSS, and vanilla JavaScript**.  
This app allows users to add, complete, and delete tasks with a clean interface.

## Live Demo

[Try the To-Do App](https://yrb1.github.io/To-Do-app/)

## Features

- Add new tasks  
- Mark tasks as completed  
- Delete tasks  
- Responsive design for all devices  
- Clear input validation  

## Tech Stack

- HTML5  
- CSS3  
- JavaScript (Vanilla JS)
